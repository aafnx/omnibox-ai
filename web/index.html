ДЛЯ ВНЕШНИХ КЛИЕНТОВ

Подключение к ИИ

Выберите OpenAI-совместимый провайдер в Jan или Pi и скопируйте Base URL и имя модели ниже.

Сетевой OpenAI API

Скопируйте Base URL и Model ниже в Jan/Pi. Панель и API могут использовать один домен и порт: панель на /, API на /v1.

Новый ключ показан один раз. Сохраните его в Bitwarden; прежний ключ больше не действует.

Настройки в Jan и Pi

  1. Выберите движок для API и сохраните. Запустите этот движок и загрузите модель.
  2. В клиенте выберите OpenAI-compatible / Custom OpenAI.
  3. Вставьте OpenAI Base URL, имя модели и сгенерированный ключ. Если ключ отключён — оставьте поле пустым; при обязательном поле укажите local.

Сохранение Base URL не создаёт DNS, сертификат или reverse proxy. Существующее перенаправление NAS → порт панели на ПК обслуживает и /v1. Встроенные API движков остаются локальными.

ПРИЛОЖЕНИЕ

Обновления

Последняя версия из приватного репозитория aafnx/omnibox-ai.

Версия и установка

—

Нажмите «Проверить обновления».

При установке серверы будут остановлены, панель перезапустится и потребуется повторный вход. Настройки подключения, пароль и API key сохраняются. После обновления запустите модель вручную.

Доступ к GitHub

Используется вход gh, подключённый к панели при установке, или отдельный вход по коду.

Подтвердите код в браузере ноутбука или смартфона. Пароль GitHub вводится на сайте GitHub.

Открыть GitHub ↗

GitHub CLI отсутствует на ПК. Установите: winget install --id GitHub.cli -e, затем ai panel restart. Либо используйте токен ниже.

Использовать токен вместо gh

Fine-grained token: репозиторий aafnx/omnibox-ai, Contents: Read. Токен используется для одного скачивания и не сохраняется.
