ДЛЯ ВНЕШНИХ КЛИЕНТОВ

Подключение к ИИ

Выберите OpenAI-совместимый провайдер в Jan или Pi и скопируйте Base URL и имя модели ниже.

Сетевой OpenAI API

Скопируйте Base URL и Model ниже в Jan/Pi. Панель и API могут использовать один домен и порт: панель на /, API на /v1.

Новый ключ показан один раз. Сохраните его в Bitwarden; прежний ключ больше не действует.

Настройки в Jan и Pi

  1. Выберите движок для API и сохраните. Запустите этот движок и загрузите модель.
  2. В клиенте выберите OpenAI-compatible / Custom OpenAI.
  3. Вставьте OpenAI Base URL, имя модели и сгенерированный ключ. Если ключ отключён — оставьте поле пустым; при обязательном поле укажите local.

Сохранение Base URL не создаёт DNS, сертификат или reverse proxy. Существующее перенаправление NAS → порт панели на ПК обслуживает и /v1. Встроенные API движков остаются локальными.
