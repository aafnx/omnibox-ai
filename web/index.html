    Сон и пробуждение
    
            
    
              
    Запускать OmniBox при включении ПК
    Только служба: панель, чат и API. Модели не загружаются.
    
              
    Модель при запуске
    Отдельная настройка. Загружается один раз после включения ПК; если её остановить, сама не вернётся.
    
              
    
              
    Выключить OmniBox
    Остановит движки, панель, чат и API; ПК останется включённым. Включить снова — команда ai on или перезагрузка ПК.
    
              
    
              Разбудить ПК можно по Wake-on-LAN, например кнопкой в Home Assistant. Пока ПК спит, панель и API недоступны.
