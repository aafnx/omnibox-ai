# OmniBox AI

Универсальная панель со светлой, тёмной и системной темами управления локальными ИИ-серверами на Windows. Версия **0.8.0**. Открывай её с ноутбука или смартфона, запускай движки, меняй настройки и управляй загрузкой моделей. Для работы с нейросетью используется отдельный клиент через API.

## Возможности

- Запуск, остановка и перезапуск серверов; **Остановить все серверы**.
- Загрузка и выгрузка моделей, скачивание Ollama-моделей и GGUF на ПК.
- Контекст и время простоя; GPU layers, Flash Attention, KV cache и batch для PrismML.
- Сохранение параметров для следующего запуска или применение сейчас, с откатом при ошибке запуска.
- Отсчёт до выгрузки и выбор размещения модели RAM/VRAM.
- Оформление по OMNIBOX Brandbook 1.0, оригинальные SVG/фавикон и локальные шрифты Inter.
- Индикаторы запуска; мониторинг CPU/RAM/GPU/VRAM и доступных температур при открытой панели.
- Текущая активность модели, метаданные запросов и input/output/total по сеансам без содержимого.
- Явные поля OpenAI Base URL, Model и API key для Jan/Pi; поддержка HTTPS reverse proxy на NAS.
- Отдельный пароль панели; `ai access` показывает адреса, `ai password reset` восстанавливает вход.
- Один управляемый движок, одна выбранная модель и одна генерация одновременно.

## Движки

| Движок | Служба в текущей конфигурации | API на ПК |
|---|---|---|
| PrismML `llama-server`, включая Bonsai PQ2 | `bonsai` | `http://127.0.0.1:18080/v1` |
| Ollama | `ollama` | `http://127.0.0.1:11434/v1` |

Панель управляет отдельными движками. Сетевой OpenAI API по пути `/v1` на порту панели (18090) передаёт запросы выбранному движку; форматы моделей не переводятся. Имена служб и пути задаются в `config.json`. Совместимые XML-профили запуска читаются самой программой; WinSW не используется.

Требуются Windows, PowerShell **7.4+** и установленные исполняемые файлы движков. Установщик переводит существующие службы на встроенный service runtime, проверяет его запуск/остановку и сохраняет прежние файлы в backups. Драйверы и модели не скачиваются автоматически. Python, Node.js, Docker и WSL для работы панели не нужны.

## Установка одним скриптом на ПК

Запусти строку в повышенной SSH-сессии **на серверном ПК**, в PowerShell 7. Репозиторий приватный: создай [GitHub token](https://github.com/settings/personal-access-tokens/new?name=omnibox-ai-install&target_name=aafnx&expires_in=1&contents=read) только для `omnibox-ai`, с **Contents: Read-only**. Токен вводится скрыто и не сохраняется.

```powershell
& { $ErrorActionPreference = 'Stop'; $token = Read-Host 'GitHub token (omnibox-ai: Contents Read)' -AsSecureString; $headers = @{}; $file = Join-Path $env:TEMP ('omnibox-ai-install-' + [Guid]::NewGuid().ToString('N') + '.ps1'); try {     $headers.Authorization = 'Bearer ' + ([pscredential]::new('github', $token)).GetNetworkCredential().Password; $headers.Accept = 'application/vnd.github+json'; $package = Invoke-RestMethod -Uri 'https://api.github.com/repos/aafnx/omnibox-ai/contents/dist/install-omnibox-ai.ps1?ref=main' -Headers $headers -MaximumRedirection 0 -TimeoutSec 60; if ($package.type -ne 'file' -or $package.encoding -ne 'base64') { throw 'GitHub не вернул установочный файл.' }; [IO.File]::WriteAllBytes($file, [Convert]::FromBase64String($package.content)); $headers.Clear(); & $file } finally {     $headers.Clear(); $token.Dispose(); if ([IO.File]::Exists($file)) { [IO.File]::Delete($file) } } }
```

Мастер спросит папку (`C:\tools\ai`), сервер по умолчанию, контекст, запуск сейчас, адрес/порт панели, разрешённые сети и пароль, а также порт/Base URL сетевого API и использование ключа. Подтверждения: `yes/no` или `y/n`; Enter сохраняет предложенное значение. Proxy можно оставить выключенным до настройки NAS. По умолчанию ИИ-сервер не запускается. Панель устанавливается отдельной службой `omnibox-ai` с автоматическим запуском.

После установки открой адрес, показанный мастером. Для текущего OmniBox при выборе `192.168.1.77` и стандартного порта: **`http://192.168.1.77:18090`**. Для API клиентов на этом ПК используйте `http://192.168.1.77:18090/v1`, либо после настройки NAS `https://llm.fnx.red/v1`. SSH-туннель не требуется. Для панели доступны LAN/VPN или HTTPS через NAS. Подробности: [установка и обновление](docs/install.md), [веб-панель и подключение](docs/web-panel.md).

## Ресурсы и простой

Панель не загружает модель при открытии. Мониторинг ресурсов включается при работающем движке и видимой вкладке, примерно раз в 3 секунды, и прекращается при остановке/сне модели или скрытии вкладки. В простое нет фонового сэмплера. Сама служба панели занимает CPU/RAM PowerShell/.NET. Мониторинг CPU/RAM использует Windows, внешние программы не нужны. Температура CPU исключена. Для GPU показывается скорость вентиляторов в %, если драйвер сообщает её.

Движки с ручным запуском остаются остановленными до команды пользователя. Таймаут простоя задаётся в настройках, для текущей установки — **30 минут**. Автоматическая выгрузка реализована самими движками; новый запрос к работающему серверу может загрузить модель снова. **Остановить все серверы** полностью останавливает настроенные движки и оставляет панель доступной.

Управляемый запуск последовательно останавливает другие движки даже при старом `exclusive:false`. Ollama/PrismML ограничиваются одной моделью/слотом. API принимает только выбранную модель, второй одновременный запрос отклоняется. Сторонние процессы и прямой запуск служб находятся вне управления программы.

## Разработка и проверки

```powershell
pwsh -NoProfile -File .\tests\test.ps1
```

```powershell
python -m unittest discover -s tests -p http_test.py -v
```

Python нужен только для второго набора тестов. Поведение JS-интерфейса дополнительно проверяется `node tests/web_test.cjs` с адаптером DOM; это не визуальный браузерный тест. Он проверяет настоящий HTTP-сервер PowerShell, вход, CSRF/Origin, ограничения запросов, журналы и фоновые операции с тестовым адаптером движков. Тесты управления проверяют XML, откат, эксклюзивность и модели без GPU. Реальные Windows-службы, ACL и Firewall нужно проверить на серверном ПК после установки.

Сборка единого установочного файла:

```powershell
pwsh -NoProfile -File .\scripts\build-setup.ps1
```
