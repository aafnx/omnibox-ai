# Установка, обновление и удаление

## Требования

- Windows 11, PowerShell 7.4 или новее (на OmniBox установлен 7.6.6).
- Повышенная SSH-сессия для установки в `C:\tools\ai` и управления службами.
- Уже зарегистрированные службы `bonsai`/`ollama`; `ai` не регистрирует их.
- Доступ к приватному репозиторию через GitHub на ноутбуке. Архив можно передать через `scp` без Git, GitHub CLI и токенов на игровом ПК.
- Для командного запускателя нужен абсолютный ASCII-путь без `%`/кавычек; стандартные `C:\tools\ai` и `C:\Program Files\PowerShell\7` подходят.

Полная процедура ZIP → scp → install есть в [README](../README.md#установка-через-ssh). Запуск из распакованного репозитория:

```powershell
pwsh -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

Или другой отдельный каталог:

```powershell
pwsh -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -InstallDirectory 'C:\tools\ai'
```

`Bypass` применяется только к запущенному процессу; глобальная execution policy не меняется. Установщик снимает отметку загрузки с известных файлов устанавливаемой программы. Не запускай программу прямо из чужого неизвестного архива.

## Что меняется

- Создаётся отдельный каталог программы и файл-маркер `.omnibox-ai-install`.
- Копируются только перечисленные файлы программы/документации.
- Создаётся JSON-конфигурация, если её ещё нет.
- Создаётся `ai.cmd` с точным путём установленного `pwsh.exe`.
- К пользовательскому PATH добавляется каталог, без дубликатов и без изменения машинного PATH.

Что **не меняется**: службы, XML WinSW, модели, драйверы, порты, SSH, игровые приложения, контекст, таймер простоя, реестр автозапуска. Никаких плановых задач не создаётся.

Установщик откажется писать в непустую чужую папку, корневую папку или поверх существующей другой команды `ai`. Установка не выполняет скрытого `Start-Service`/`Stop-Service`.

## PATH через SSH

Инсталлятор запускается дочерним PowerShell-процессом, поэтому он не может изменить окружение родительской SSH-сессии. Для текущей сессии выполни:

```powershell
if (@($env:Path -split ';' | Where-Object { $_.TrimEnd('\') -ieq 'C:\tools\ai' }).Count -eq 0) { $env:Path += ';C:\tools\ai' }
```

Пользовательский PATH сохранён постоянно, но уже запущенный `sshd` может наследовать старое окружение. Если даже новая SSH-сессия не видит `ai`, используй `C:\tools\ai\ai.cmd` или добавляй PATH в текущую сессию. После следующей обычной перезагрузки ПК новая служба получит обновлённое окружение. Перезапускать `sshd` в активной SSH-сессии установщик не будет.

## Проверка установки без переключения серверов

```powershell
ai version
```

```powershell
ai config
```

```powershell
ai status
```

Проверка управления (меняет состояние только по твоей явной команде):

```powershell
ai start bonsai
```

```powershell
ai stop
```

## Обновление

Скачай новый ZIP и повтори процедуру установки из новой временной папки. `config.json` не перезаписывается. Существующие файлы программы и конфигурации копируются в `C:\tools\ai\backups\<дата-время-идентификатор>` перед заменой.

Работающие службы не перезапускаются. Изменения в примерной конфигурации не применяются к локальной автоматически — при необходимости сравни их вручную.

Для исходников с Git: `git pull --ff-only` в рабочем репозитории, затем повторный `install.ps1`. Не используй `git reset --hard` как способ обновления.

## Откат

Выбери конкретный backup по напечатанному пути. Восстанови `ai.ps1`, `ai.cmd`, `src`, документацию и при необходимости `config.json` из этой копии. Сам backup содержит старую конфигурацию; текущий JSON откатывать необязательно. Службы и модели не зависят от версии оболочки.

## Удаление оболочки

Сначала реши, надо ли оставлять сервер работающим. `ai stop` останавливает ИИ-серверы; удаление файлов самой оболочки **не остановит их**.

Удалить только запись этой программы из пользовательского и текущего PATH:

```powershell
$aiDirectory = 'C:\tools\ai'; $userEntries = @([Environment]::GetEnvironmentVariable('Path', 'User') -split ';' | Where-Object { $_ -and [Environment]::ExpandEnvironmentVariables($_).TrimEnd('\') -ine $aiDirectory }); [Environment]::SetEnvironmentVariable('Path', ($userEntries -join ';'), 'User'); $env:Path = (@($env:Path -split ';' | Where-Object { $_.TrimEnd('\') -ine $aiDirectory }) -join ';')
```

После этого папку `C:\tools\ai` можно переместить в архив/корзину вручную. Не удаляй `C:\ai`, `C:\tools\bonsai` или `C:\tools\ollama`: там движки и модели, а не эта оболочка. Удаление/перемещение оболочки не отменяет зарегистрированные Windows-службы.
