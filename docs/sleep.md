# Сон и пробуждение ПК

Панель усыпляет ПК кнопкой «Перевести ПК в сон» на обзоре. Если сейчас идёт генерация, скачивание модели, установка движка или обновление, кнопка откажет — сначала дождитесь окончания или остановите сервер. Пока ПК спит, панель и API недоступны: разбудить ПК сама панель не может, поэтому пробуждение настраивается в Home Assistant.

## 1. Wake-on-LAN на ПК (Windows)

1. В BIOS/UEFI включите «Wake on LAN» / «Power On By PCI-E» (название зависит от платы).
2. Диспетчер устройств → сетевой адаптер → «Управление электропитанием»: включите «Разрешить этому устройству выводить компьютер из ждущего режима» и «Разрешать вывод компьютера из ждущего режима только с помощью магического пакета».
3. Там же, «Дополнительно»: «Wake on Magic Packet» — «Включено».
4. Панель управления → Электропитание → «Действия кнопок питания»: выключите «Быстрый запуск» (иначе после выключения ПК может не проснуться по сети).

MAC-адрес адаптера показан в панели: «Подключение» → «Сон и пробуждение».

## 2. Кнопка в Home Assistant

`configuration.yaml`:

```yaml
wake_on_lan:

script:
  wake_omnibox:
    alias: Разбудить OmniBox
    icon: mdi:desktop-tower-monitor
    sequence:
      - service: wake_on_lan.send_magic_packet
        data:
          mac: "aa:bb:cc:dd:ee:ff"          # MAC из панели
          broadcast_address: 192.168.1.255
```

Можно также добавить интеграцию «Wake on LAN» через интерфейс HA (Настройки → Устройства и службы): она создаёт кнопку сразу.

Проверка, что ПК проснулся (например, для карточки на панели HA):

```yaml
binary_sensor:
  - platform: ping
    host: 192.168.1.77
    name: OmniBox
    count: 2
    scan_interval: 30
```

Опрос идёт от Home Assistant, а не от OmniBox: программа в простое ничего не опрашивает.

## 3. Через WireGuard

Магический пакет не проходит через WireGuard сам: нажмите кнопку в Home Assistant (через его приложение или веб-интерфейс), а HA отправит пакет в локальную сеть. После пробуждения служба OmniBox уже работает; модель запускается из панели.
