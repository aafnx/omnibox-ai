# Прототип интерфейса 0.21

`prototype.html` — согласованный с владельцем кликабельный прототип нового интерфейса: чат с веб-поиском и ассистентами, единый список моделей (локальные и OpenRouter), сервер, настройки. Данные в нём примерные.

Опубликованная версия для комментариев владельца: https://claude.ai/artifact/BosHvJS6sjk8sUq1TZL4gw. Правки владелец оставляет комментариями в артефакте; после правок файл здесь обновляется той же версией.

Прототип — эталон поведения и вида; панель (`web/`) реализует его на настоящих данных службы. Расхождения считаются ошибками панели, если владелец не решил иначе.
