# Веб-панель OmniBox AI

Основной интерфейс версии 0.6.0 — светлая панель управления ИИ-серверами. Она не содержит чат и не заменяет Jan, Pi или другой клиент: работа с нейросетью идёт через API выбранного движка.

## Установка и вход

Запусти [однострочный установщик](install.md) прямо на Windows-ПК через повышенную SSH-сессию. Мастер дополнительно спросит IP/DNS-имя ПК, порт панели, разрешённые адреса Firewall и пароль. По умолчанию порт **18090**, доступ — из локальной подсети. На текущем OmniBox адрес будет `http://192.168.1.77:18090`, если выбрать IP `192.168.1.77`.

Пароль панели отдельный от Windows и SSH. Можно ввести пароль от 12 символов или нажать Enter: установщик сгенерирует пароль и покажет его один раз. Сохрани его в Bitwarden. В `panel.json` остаются только соль и PBKDF2-SHA256 hash. Повторная установка сохраняет пароль. Для сброса через доверенную SSH-сессию останови службу `omnibox-ai`, перемести `panel.json` в защищённый архив и повтори установщик с новым паролем.

Служба `omnibox-ai` запускается автоматически с Windows и остаётся доступной независимо от SSH-сессии. Bonsai/Ollama не запускаются от открытия панели; существующие типы их запуска не меняются. Используется уже установленный WinSW, Python, Node.js, Docker и WSL не нужны.

## Обзор

- Состояние служб, готовность API, текущая модель и контекст.
- Состояние сна Bonsai, настроенное время простоя.
- Запуск и остановка каждого движка; **Остановить все серверы**.
- Результаты операций и ошибки, включая сообщения автоматического отката.
- Видеопамять: обновляется при входе и по кнопке **Обновить**. Периодического опроса `nvidia-smi` нет.

Статус обновляется раз в 8 секунд, только пока вкладка видима. При закрытой/скрытой панели опроса нет. На стороне панели нет постоянного опроса GPU/моделей или собственных таймеров пробуждения. Открытая вкладка запрашивает только метаданные движков; она не генерирует запросы к модели для проверки готовности.

Служба панели использует CPU/RAM самого PowerShell/.NET. Это небольшой постоянно запущенный управляющий процесс, а не нулевая нагрузка. GPU нужен только ИИ-движкам. Остановка всех серверов оставляет панель доступной для следующего запуска.

## Модели и настройки

Выбери движок. Панель читает его XML WinSW; отдельного дублирующего файла настроек моделей нет.

| Элемент | Действие |
|---|---|
| Сохранить | Записать настройки для следующего запуска; активная модель не перезапускается |
| Применить и запустить | Сохранить параметры и перезапустить/запустить выбранный сервер |
| Восстановить предыдущие | Вернуть предыдущий XML; повторно запускать только ранее работавшую службу |
| Загрузить | Bonsai: применить форму и загрузить GGUF. Ollama: загрузить выбранную установленную модель |
| Выгрузить | Bonsai: остановить службу и освободить модель/кеш. Ollama: выгрузить все модели, сохранив API работающим |

Для **Bonsai/PrismML** доступны локальный GGUF, API-alias, контекст, время простоя, GPU layers, Flash Attention, K/V cache, batch/micro-batch. Список GGUF берётся из каталога текущей модели. Projector-файлы и ссылки не предлагаются как текстовые модели. Vision-projector автоматически не подключается. Другие аргументы, порт и тип запуска сохраняются.

Для **Ollama** доступны серверные defaults контекста и keep-alive. Модели на диске отображаются, когда API Ollama запущен. Загрузка использует пустой запрос `/api/generate`; генерация текста для прогрева не запускается. Настройки GPU/offload для Ollama определяет runtime — параметры PrismML не выдаются за общие для всех движков.

Контекст: `32k=32768`, `128k=131072`, `192k=196608`. Большой контекст должен поддерживаться моделью и помещаться в память. Автоматический откат действует при ошибке запуска после сохранённого изменения. Успешный старт API Ollama не гарантирует загрузку любой модели позже; OOM при последующей генерации этим механизмом не отслеживается. Клиент Ollama может переопределить defaults через `num_ctx`/`keep_alive`.

## Скачивание моделей

- **Ollama:** введи имя с тегом из библиотеки или поддерживаемое Ollama имя Hugging Face, затем нажми **Скачать на ПК**. Ollama должен быть запущен. Скачивание само не запускает сервер.
- **PrismML:** введи прямую HTTPS-ссылку вида `https://huggingface.co/owner/repo/resolve/main/file.gguf`, безопасное имя файла и, при наличии, SHA256 от автора. Файл сохраняется рядом с текущим GGUF. Существующие модели не перезаписываются. Проверяются заголовок GGUF и указанная контрольная сумма; это не проверка качества/совместимости модели.

Скачивание не загружает модель в VRAM и не переключает движки. Для больших файлов результат может появиться через несколько минут; панель остаётся доступной. Одновременно допускаются одна операция управления и одно скачивание. Остановка сервера Ollama во время его скачивания может оборвать загрузку; ошибка отобразится в операциях. Прерванный GGUF `.part` удаляется при штатной обработке ошибки. После аварийного выключения собственный `.download-<GUID>.part` можно удалить вручную.

В **Каталоге моделей** доступен поиск Hugging Face, список вариантов GGUF и скачивание выбранного файла. Для Ollama отправляется `pull hf.co/author/repo:filename`; специальные Bonsai PQ2/PTQ1 файлы через Ollama не предлагаются. [Поиск и источники моделей](models.md).

## Подключение Jan/Pi напрямую по сети

В **Подключение → Сетевой OpenAI API** выбери движок, Base URL и режим ключа. API доступен по `/v1` на порту панели — **18090**, текущий прямой адрес — **`http://192.168.1.77:18090/v1`**. Для NAS можно сохранить **`https://llm.fnx.red/v1`** после настройки HTTPS upstream.

В клиенте выбери OpenAI-compatible / Custom OpenAI provider. Крупное поле **OpenAI Base URL** копируется в Base URL; рядом показано имя модели. SSH-туннель не нужен. Порт панели **18090** остаётся только для управления.

**Сгенерировать новый API key** показывает ключ один раз и отзывает старый. Сохрани ключ в Bitwarden. Флажок **Требовать API key** позволяет включить/отключить авторизацию; без неё оставь поле клиента пустым или укажи `local`, если клиент требует значение. Пароль панели не используется для API.

API передаёт запрос выбранному движку. Выбор не запускает службу; остановленный backend возвращает 503. [Маршруты, ограничения и настройка API reverse proxy](model-api.md).

## Доступ извне

По IP ПК панель доступна только из разрешённых установщиком сетей. Для VPN при необходимости укажи его подсеть в параметре Firewall, например `LocalSubnet,10.10.0.0/24`. DNS/IP панели должен присутствовать в `panel.json → allowed_hosts`; при смене адреса повтори установку с новым PanelHost.

Для доступа через существующий SSH, без открывания HTTP-порта извне:

```powershell
ssh -N -o ExitOnForwardFailure=yes -L 18090:127.0.0.1:18090 avoq@192.168.1.77
```

Затем открывай `http://127.0.0.1:18090` на ноутбуке. Этот необязательный туннель также предоставляет API через `http://127.0.0.1:18090/v1`. Для LAN/NAS туннель не нужен. Используй свой доступный внешний SSH/VPN-адрес вместо локального примера.

HTTP не шифрует пароль и сессию. Панель предназначена для доверенной LAN/VPN или SSH-туннеля; не публикуй порт напрямую в интернете. Для HTTPS через NAS предусмотрен proxy-режим: установщик принимает внешний origin и IP NAS; Cookie становится Secure, Origin проверяется по внешнему адресу. Встроенного TLS нет; сертификат и TLS termination настраиваются на NAS. [Пошаговая настройка NAS reverse proxy](reverse-proxy.md).

Сохранение внешнего Base URL не создаёт DNS/сертификат или правило NAS. Установщик публикует отдельный HTTP-вход API на ПК; внешний HTTPS настроен на NAS отдельным правилом.

## Ограничения и обслуживание

Платформа первой веб-версии — Windows + PowerShell 7.4+ с существующими WinSW-службами. Linux, создание новых backend, автоматическая установка runtime/драйверов и полноценная маршрутизация нескольких моделей PrismML не реализованы.

CLI сохранён для диагностики, установки и восстановления при недоступной панели. Повседневное управление выполняется в браузере. Журналы панели: `C:\tools\ai\logs\panel-service.*.log`. Порт, пароль и hosts панели хранятся в `panel.json`; параметры сетевого API и hash ключа — в `gateway.json`. Оба файла исключены из Git. Код/конфигурация панели защищены Windows ACL: SYSTEM, Administrators и пользователь установки. Не переноси её в общий каталог с правом записи для других пользователей.

Источники: [Ollama API](https://docs.ollama.com/api), [PrismML server](https://github.com/PrismML-Eng/llama.cpp/blob/prism/tools/server/README.md), [HttpListener](https://learn.microsoft.com/en-us/dotnet/fundamentals/runtime-libraries/system-net-httplistener).
