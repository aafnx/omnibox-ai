# Бренд OMNIBOX

Источник правил — [OMNIBOX Brand Book 1.0](OMNIBOX-brandbook.pdf) (2026). Ниже — выжимка для панели; при расхождении прав брендбук.

## Характер

Спокойная уверенность: тёмный экран, свет только там, где он нужен. Без «геймерской» эстетики, неона и мигания.

## Палитра

| Имя | Цвет | Где |
|---|---|---|
| Void | `#000000` | фон тёмной темы |
| Deep Night | `#0A0C1F` | подложки, карточки тёмной темы; текст светлой |
| Signal | `#DEE4EE` | текст на тёмном |
| Ice | `#BEEFFF` | начало градиента |
| Iris | `#7C6CFF` | главный акцент: основные кнопки, активная навигация, ссылки |
| Ember | `#FF9654` | конец градиента |
| Amber | `#FFBE78` | тёплый вспомогательный |
| Neon `#F24DFF`, Ocean `#3C8CFF` | — | только дополнительная серия настроения; в интерфейсе не используются |

Градиент «Свет» — Ice → Iris → Ember по диагонали, тёплая сторона справа снизу. Порядок цветов не меняется. В панели градиент — линия под заголовком и заполнение шкал.

## Логотип

- Горизонтальный lockup: знак слева, надпись справа. Диаметр знака = 2,6 × высоты прописной, зазор = 0,42 × диаметра.
- Охранное поле — половина диаметра знака со всех сторон.
- Минимум: знак 16 px, надпись 80 px в ширину.
- Цельный (Solid) знак — иконки, малые размеры, светлый фон. Светящийся (Lit) — только экраны и только на чёрном.
- Файлы: `web/brand-light.svg`, `web/brand-dark.svg` (lockup **OMNIBOX AI**), `web/favicon.svg` (знак).

Нельзя: растягивать lockup, менять порядок градиента или перекрашивать кольцо, ставить Lit-знак на светлый фон, добавлять знаку тени и обводки, набирать надпись другим шрифтом или строчными, нарушать охранное поле.

## Шрифты

- **Michroma** — надпись логотипа (только прописные, трекинг 24 %) и акцентные заголовки/экранные метки: только прописные, трекинг 12–32 %. В панели Michroma используется только в логотипе (в контурах), поэтому кириллические заголовки набраны Inter прописными с разрядкой.
- **Inter 400/600** — текст и подписи интерфейса. Шрифт лежит в `web/` (`inter-*.woff.base64`), внешние запросы не нужны.

## Движение

Медленно и плавно, ничего не мигает. «Дыхание» — период 4 с, амплитуда ±13 %. Знак никогда не вращается.

## Как это применено в панели

- Тёмная тема: фон Void, карточки Deep Night, текст Signal, акцент Iris. Синего нет.
- Заголовки страниц и метки карточек — прописные с разрядкой; обычный текст — Inter, не меньше 12 px.
- Иконки навигации и кнопок — линейные SVG в цвете текста, без эмодзи.
- Индикатор долгой операции «дышит» (4 с, непрозрачность ±13 %), а не мигает.
