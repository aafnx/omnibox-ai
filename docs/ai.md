# Команда ai

`ai` управляет OmniBox AI на этом компьютере. Запускайте её в терминале **от имени администратора** (Linux — через `sudo`): она обращается к службе через локальный канал, доступный только администраторам.

| Команда | Что делает |
|---|---|
| `ai status` | движки, модели, контекст, адрес панели и API |
| `ai start prismml` / `ai start ollama` | запустить движок (другой остановится) и дождаться готовности |
| `ai stop [движок]` | остановить движок; без имени — все |
| `ai restart <движок>` | перезапустить с текущими настройками |
| `ai logs [движок]` | последние строки журналов |
| `ai password reset` | новый пароль панели; показывается один раз, все входы завершаются |
| `ai key new` | один новый API key вместо всех прежних — если ключ мог утечь; прежние сразу перестают действовать. Отдельные ключи для клиентов — в панели |
| `ai on [движок]` | включает OmniBox: запускает службу панели и API, ждёт её готовности и запускает модель — движок из аргумента или выбранный «при старте» |
| `ai off` | выключает всё: движки, затем панель и API |
| `ai autostart [on\|off]` | запускать ли OmniBox вместе с Windows (служба `omnibox`: автоматически или вручную); без аргумента — текущее состояние |
| `ai autostart model <prismml\|ollama\|off>` | какая модель запускается при загрузке ПК (по умолчанию — никакая) |
| `ai uninstall` | удаляет программу; данные и модели — только если ответить «да» на отдельные вопросы |
| `ai update [версия]` | скачивает выпуск (последний или указанный), проверяет SHA256 и обновляет программу с откатом при сбое. Нужен вход в `gh` или GitHub token (`GH_TOKEN`, иначе запрашивается скрыто и не сохраняется) |
| `ai version`, `ai help` | версия и справка |

Если служба не отвечает: Windows — `sc.exe start omnibox`, Linux — `systemctl start omnibox`; журнал службы — в журнале событий Windows или `journalctl -u omnibox`.
