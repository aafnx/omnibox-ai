# Поиск и скачивание моделей

Раздел **Модели и настройки → Каталог моделей** показывает ссылки на [Hugging Face](https://huggingface.co/models), [Ollama Library](https://ollama.com/library) и [Bonsai/PrismML](https://github.com/PrismML-Eng/Bonsai-demo).

## Каталог в панели

1. Выбери движок, для которого скачиваешь модель.
2. Введи название/автора в поиск Hugging Face. Быстрые запросы: Bonsai, uncensored, abliterated.
3. Панель покажет до 12 GGUF-репозиториев со страницами авторов и числом скачиваний. Открой описание и лицензию.
4. Нажми **Выбрать GGUF**, посмотри варианты файлов и размер, если он указан источником.
5. Нажми **Скачать на ПК**. Результат операции появится в обзоре.

Поиск и список файлов выполняются только по запросу пользователя в отдельном задании. Фонового обновления каталога нет. При недоступности Hugging Face показывается ошибка; ссылки на источники и ручная форма остаются доступны. В этой среде внешний API Hugging Face был недоступен: протокол и обработка метаданных проверены тестовым адаптером, реальный поиск нужно проверить с ПК.

Для PrismML файл сохраняется рядом с текущим GGUF, с именем, включающим автора/репозиторий. Если источник возвращает commit SHA, ссылка закрепляется на него. При наличии SHA256 он проверяется после скачивания. Для Ollama передаётся имя `hf.co/author/repo:filename.gguf`; Ollama должен быть заранее запущен. Это скачивание в хранилище Ollama, а не импорт файла из каталога PrismML.

**Bonsai 2 PQ2/PTQ1 требует PrismML.** Каталог блокирует скачивание известных специальных форматов через Ollama. Наличие расширения GGUF не гарантирует поддержку архитектуры конкретным runtime. Для многотомных файлов кнопка отключена: загрузчик первой версии не устанавливает набор split GGUF. Projector/mmproj файлы не предлагаются как самостоятельные текстовые модели. Приватные/gated репозитории через каталог без Hugging Face credentials могут быть недоступны.

## Ручная загрузка

- Ollama: найди модель и тег в его Library, скопируй `имя:тег` в **Скачать новую модель**.
- PrismML: вставь прямую HTTPS-ссылку Hugging Face `/resolve/.../file.gguf`, имя файла и при наличии SHA256.

Существующие файлы не перезаписываются. Скачивание не загружает модель в VRAM, не переключает движки и не меняет выбранную модель автоматически. После завершения выбери установленную модель и нажми **Загрузить**.

Размер весов — только часть потребления памяти: KV-кеш/контекст и runtime требуют дополнительную память. Скачивания и метки uncensored/abliterated не являются проверкой качества, совместимости или отсутствия отказов. Сортировка по скачиваниям — навигация по каталогу, не обещание лучшей модели.

## MoE-модели: Ornith 1.5 35B-A3B

[Ornith 1.5 35B-A3B](https://huggingface.co/ornith-ai/Ornith-1.5-35B-A3B-GGUF) — MoE на архитектуре Qwen3.5-MoE: 35B параметров, из них около 3B активны на токен. Q4_K_M весит около 21 ГБ и целиком в 16 ГБ VRAM не помещается. У MoE-моделей большую часть весов занимают эксперты, а на каждый токен работают лишь некоторые из них, поэтому экспертов держат в RAM, а внимание, общие веса и KV-кеш — на GPU. Скорость при этом остаётся высокой.

vLLM для этой модели не используется: на Windows он работает только через WSL2/Docker и держит все веса в VRAM.

1. Нужен llama-server PrismML с поддержкой `qwen35moe` и `--n-cpu-moe` — сборка `prism-b10754` (2 октября 2026) или новее из [релизов PrismML](https://github.com/PrismML-Eng/llama.cpp/releases), вариант `win-cuda-13.3-x64` или `win-cuda-12.4-x64` вместе с `cudart`. Bonsai PQ2 в этих сборках работает по-прежнему.
2. **Модели и настройки → Каталог моделей** (движок Bonsai): найди `Ornith-1.5-35B-A3B GGUF`, открой репозиторий [ornith-ai](https://huggingface.co/ornith-ai/Ornith-1.5-35B-A3B-GGUF) или [bartowski](https://huggingface.co/bartowski/Ornith-1.5-35B-A3B-GGUF) и скачай однофайловый `Q4_K_M`. Нужно около 22 ГБ на диске; скачивание идёт в фоне.
3. Выбери GGUF, имя модели в API — например `ornith-1.5-35b-a3b`; размещение — **VRAM · GPU**.
4. **Параметры GPU и кеша → Слои MoE в RAM**: начни с `20`. Если запуск не прошёл из‑за памяти (панель откатит настройки), увеличь значение; если в обзоре свободно больше 2 ГБ VRAM, уменьши — больше экспертов на GPU даёт больше токенов в секунду. `999` — все эксперты в RAM, минимум VRAM.
5. Контекст: модель поддерживает 256K, но для 16 ГБ VRAM разумно 32k–64k с кешем `q8_0`. Нажми **Применить и запустить**.

Настройка хранится в XML-профиле движка как `--n-cpu-moe N`. Для обычных (не MoE) моделей, включая Bonsai, она ничего не меняет.

Источники: [Hugging Face HfApi](https://huggingface.co/docs/huggingface_hub/en/package_reference/hf_api), [GGUF через Ollama](https://huggingface.co/docs/hub/ollama), [форматы Bonsai](https://github.com/PrismML-Eng/Bonsai-demo/blob/main/MODEL-FORMATS.md).
