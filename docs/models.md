# Модели: настройки и скорость

## Пресет «Базовый»

«Базовый» — рекомендуемые настройки для этого ПК (RTX 5080, 16 ГБ VRAM). Он встроен, его нельзя удалить, и он первый в списке пресетов в разделе «Модели и настройки». Новый движок PrismML сразу получает его значения.

При применении пресет подбирается под выбранную модель и видеокарту:

- Flash Attention включён, KV-кеш `q8_0` (вдвое меньше `f16` почти без потери качества), batch 2048 и ubatch 512 — быстрее читает длинные запросы;
- контекст — самый длинный из 128k, 64k, 32k, 16k, 8k, при котором веса и KV-кеш целиком помещаются в VRAM с запасом 0,75 ГБ для Windows и браузера; не длиннее обученного контекста модели;
- если модель больше VRAM: у MoE-моделей эксперты части слоёв уходят в RAM («Слои MoE в RAM»), у обычных — часть слоёв на GPU («RAM + VRAM»);
- модель, имя в API, Thinking и сэмплинг пресет не меняет.

Расчёт идёт по заголовку GGUF (слои, головы KV, обученный контекст) и объёму VRAM из `nvidia-smi`; у гибридных моделей (Qwen3.5/3.6) KV-кеш учитывается только для слоёв полного внимания. Работающий сервер перезапускается с новыми настройками; если запуск не удался, настройки откатываются.

## Почему модель вдруг медленная

Если веса и KV-кеш не помещаются в VRAM, а размещение — «VRAM · GPU», Windows не сообщает об ошибке: видеодрайвер NVIDIA выносит часть памяти в RAM, и генерация замедляется в 5–10 раз. Типичная причина — большой контекст с кешем `f16`: для 27B-модели контекст 192k с `f16` занимает больше 16 ГБ.

Панель проверяет это сама: при открытии «Модели и настройки» и при смене модели, контекста, типа кеша или размещения. Если настройки не помещаются, над кнопками появится предупреждение с кнопкой **Применить «Базовый»**. Проверка читает только заголовок GGUF и запускается по действию, без фонового опроса.

Чтобы переполнение не замедляло работу молча, а сразу приводило к понятной ошибке запуска (и панель откатывала настройки), в панели управления NVIDIA можно выключить перенос памяти: **Управление параметрами 3D → Программные настройки → `llama-server.exe` → CUDA — политика отката системной памяти → Предпочитать отсутствие отката**.

## Как сравнить

После смены настроек нажмите **Тест модели**: он показывает время до первого токена и скорость генерации в ток/с. «Оценить размещение в VRAM/RAM» показывает, сколько займут веса и KV-кеш с текущими настройками.
